# VisionBridge AI - Data Directory

This directory stores sample test images, benchmarks, and dataset references for evaluating VisionBridge AI's accessibility modules.

## Directory Structure

- `sample_images/`: Synthetic and curated evaluation images depicting indoor, outdoor, reading, and low-light scenarios.
- `evaluation/`: Ground-truth annotations for precision, recall, and OCR Character Error Rate (CER) testing.
- `captured/`: Temporary directory for local user-captured frames (strictly local, never uploaded without user consent).

## Privacy & Ethical Data Statement

In compliance with OpenCV AI Competition guidelines and ethical accessibility engineering:
- Personal recordings, face embeddings, and unconsented images are **strictly forbidden** from being committed or transmitted to any third party.
- All evaluation images included in this repository are synthetic, self-generated, or CC0/public-domain benchmark samples.
